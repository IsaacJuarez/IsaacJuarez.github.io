Lo que hacemos

Trabajamos donde los estándares de salud se encuentran con sistemas reales: equipos de distintos fabricantes, hospitales con varias sedes y datos de pacientes que no pueden perderse.

  • Integración DICOM

    Servicios que reciben, consultan, recuperan y envían estudios entre modalidades, estaciones de trabajo y PACS, con monitoreo y reintentos.

    SCP y SCU, C-ECHO, C-FIND, C-MOVE, C-STORE

  • Flujo radiológico

    Sistemas RIS que ordenan el trabajo diario: registro del paciente, seguimiento del estudio y control de estudios dictados.

    RIS, worklist, flujo de dictado

  • Archivo y enrutamiento

    Envío automático de estudios desde repositorios locales hacia archivos centrales, sincronización entre sedes y vigilancia de carpetas.

    VNA, PACS, multi-sitio

  • Interoperabilidad clínica

    Intercambio de órdenes, resultados y datos demográficos con los sistemas del hospital, cuidando la información de cada paciente.

    HL7, FHIR, validación de CURP

  • Aplicaciones clínicas web

    Interfaces modernas y APIs para el personal médico y administrativo, construidas para mantenerse durante años.

    .NET, Java, Angular, TypeScript

Trayectoria

De servicios de red DICOM a plataformas web completas, siempre dentro de imagen médica.

  1. 2017

    Infraestructura DICOM. Servicios de recepción y envío, consolas de configuración de nodos y un primer RIS ligero.

  2. 2020

    APIs web. Arquitecturas de servicios para exponer información clínica a aplicaciones web.

  3. 2024

    PACS abiertos. Integración completa de consulta, recuperación y almacenamiento sobre plataformas de código abierto.

  4. 2025

    Front-end moderno y datos de identidad. Aplicaciones Angular con estándares de calidad y utilidades de validación de CURP.

  5. 2026

    Nueva generación de RIS. Plataforma web en TypeScript que reemplaza la operación heredada.

Cómo trabajamos

La tecnología en salud no admite improvisación. Estas reglas guían cada proyecto.

Estándares primero

Seguimos DICOM y HL7 al pie de la letra para que nuestro software conviva con equipos de cualquier fabricante.

El paciente en el centro

Los datos clínicos se tratan con el mínimo acceso necesario, trazabilidad y decisiones documentadas.

Lo heredado también cuenta

Modernizamos sin detener la operación: los sistemas actuales siguen funcionando mientras llega la nueva versión.
